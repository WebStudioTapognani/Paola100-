# Come si scrive un prompt per un atto

In questo capitolo: lo schema di prompt che funziona per i testi amministrativi e il metodo del file di stile.

## Lo schema in cinque parti

1. Ruolo: chi deve essere l'IA.
2. Contesto: ente, ufficio, procedimento, norme di riferimento.
3. Compito: cosa deve produrre.
4. Formato: struttura dell'atto (premesse, visti, considerato, dispositivo).
5. Vincoli: stile, lunghezza, cosa non inventare.

```
Sei un istruttore amministrativo di un Comune italiano.
[contesto]
Scrivi [tipo di atto] su [oggetto].
Struttura: [premesse / visti / considerato / dispositivo].
Stile: asciutto, impersonale, frasi brevi, niente aggettivi superflui.
Non inventare norme: se ti serve un riferimento che non ti ho dato, scrivi [VERIFICARE].
```

## Il metodo del file di stile

L'IA scrive come un comunicato stampa. Ogni ufficio ha invece il suo stile, e di solito è quello del responsabile che firma.
